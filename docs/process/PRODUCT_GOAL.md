# Product Goal

The single overarching objective the whole Product Backlog serves (Scrum
2020): a VS Code extension that generates a complete, idiomatic Spring Boot
4.1.x / Java 25 service — model through REST layer through tests — from a
model definition, in three input forms (webview form, existing Java model
class/package, or a YAML file), with optional AWS deployment, published
open source and discoverable by the Spring community.

Epics exist to deliver a piece of this goal. A Story that doesn't trace back
to it, even loosely, is probably out of scope.

## Roles

- **Product Owner / Scrum Master**: the repo owner (Liviu) — decides what
  matters, approves architecture and scope changes, can pause the process
  at any time.
- **Developers**: Claude Code agents (interactive sessions, and any
  scheduled routine added later) — implement, test, review, and close
  Stories/Tasks against this Product Goal.
